# Captação de Clientes

Mini CRM para captar e acompanhar leads, feito com Expo, TypeScript e SQLite.

## Funcionalidades
- Cadastro, edição e exclusão de clientes
- Lista com busca por nome/empresa e filtro por status
- Detalhe com funil (Novo, Em contato, Convertido, Perdido)
- Ligação e WhatsApp direto pelo app

## Como rodar
npm install
npx expo start
